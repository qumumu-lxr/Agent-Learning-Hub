# Research Summary Skill

Name: research_summary
Description: Turn short source notes into a compact cited-style summary.

## When to use

Use this skill when the user asks for a short research summary from known source notes.

## Procedure

1. Read the source notes.
2. Extract at most three key points.
3. Render them with the summary template.
4. Check the output before returning.

## Smoke test checks

- must include bullet points
- must include takeaway
- must use source text
